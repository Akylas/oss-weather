## Latest release

The [GitHub releases page](https://github.com/ossappscollective/oss-weather/releases/latest) has the latest version number, release notes, Android APKs and the Mac app.

## Verify the Android app

**Package name:** `com.akylas.weather`

**SHA-256 signing certificate fingerprint:**

```
68:70:80:D4:CF:6F:CF:FE:8D:82:FD:1D:78:3C:90:C2:95:94:80:AA:13:C3:8A:D8:D0:4E:C3:40:66:FC:13:F1
```

Use [AppVerifier](https://github.com/soupslurpr/AppVerifier) or a similar tool.
