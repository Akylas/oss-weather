# First Steps

There is no setup wizard: the app works out of the box with Open-Meteo, which needs no account or API key. These steps get you set up in a minute.

## 1. Choose a location

On first launch the main screen says you haven't chosen a location yet, and offers three buttons:

- **My location**: uses your GPS position (the app asks for location permission).
- **Search location**: search for a place by name.
- **Select location on map**: pick a point on a map.

Later you can do the same from the action bar: the search icon, or the overflow menu (⋮) with **Find GPS location** and **select location on map**.

## 2. Save your favorites

Tap the **star** in the action bar to add the current location to your favorites. Open the favorites drawer with the menu icon (☰) or by swiping from the left edge.

In the drawer you can:

- tap a favorite to show it
- long press and drag to reorder
- use a row's ⋮ menu to rename, duplicate or remove it, or change its provider

See [Basic usage](/guide/basic-usage#favorites-drawer) for details.

## 3. Pick a weather provider

The default provider is **Open-Meteo**. To change it, go to **Settings > Providers > Provider**. You can also set a different provider for a single favorite from its ⋮ menu.

OpenWeather and AccuWeather need your own API key, entered in **Settings > Providers**. See [API keys](/guide/api-keys) and [Weather providers](/guide/weather-providers).

## 4. Units, language and look

Open **Preferences** from the overflow menu (⋮):

- **Units**: switch to imperial units, or choose each unit yourself.
- **Language & locales**: app language (or "auto"), 24-hour clock, daily date format.
- **Appearance**: theme (Auto, Light, Dark, Black), color theme, font scale, and the modern or classic design style.
